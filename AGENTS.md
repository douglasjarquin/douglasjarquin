# AGENTS.md

This repository is the GitHub profile README for douglasjarquin ([github.com/douglasjarquin](https://github.com/douglasjarquin)).

Doug is based in Davie, Florida and is Director of DevOps at Zumba Fitness. He has been building for the web since 2004. Today he leads DevOps for a global platform and builds operated software, native macOS tools, and developer infrastructure.

Featured projects on the profile:

- [Pinchos](https://github.com/douglasjarquin/pinchos) — declarative, native macOS menu-bar items from one TOML file
- [Sum](https://github.com/douglasjarquin/sum) — dispatch approved work to isolated agents
- [Remainder](https://github.com/douglasjarquin/remainder) — one-shot Go CLI to read remaining LLM quota from local credentials
- [Go Toon](https://github.com/douglasjarquin/go-toon) — community-driven Go implementation of TOON
- [SF2 Themes](https://github.com/douglasjarquin/sf2-themes) — Street Fighter II-inspired theme pack
