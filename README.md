## How I work

- **Operate what I build.** Reliability, observability, backups, and recovery are part of the product.
- **Use boring foundations.** Small services, clear interfaces, PostgreSQL, and infrastructure that can be explained.
- **Keep work close to the machine.** Native and local-first when the job allows it.
- **Treat agents as tools, not owners.** Automation can write and run a lot; a human still reviews and accepts responsibility.
